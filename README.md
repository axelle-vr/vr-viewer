# VR-viewer starter

Bekijk je bouwkundige constructie in VR op de Meta Quest, zonder terminal of commando's.

Kies je map met VR-modellen (HTML-pagina's), klik op **Start**, en open de getoonde link in de browser van je Quest.

## Downloaden

Ga naar **Releases** (rechts op deze pagina) en download `VR-viewer-starter-setup.exe`.

Windows toont bij de eerste keer misschien *"Windows heeft uw pc beveiligd"*. Klik dan op **Meer informatie → Toch uitvoeren**. Dat komt doordat de app niet digitaal ondertekend is.

## Wat heb je nodig?

- Een Windows-computer
- Een Meta Quest 2, 3 of Pro
- Een gratis account op [ngrok.com](https://ngrok.com) (de app helpt je bij het instellen)

## Gebruik

1. Kies je hoofdmap met VR-modellen (bv. `C:\VR-modellen`). Modellen mogen elk in een eigen submap staan.
2. Download ngrok met de knop in de app en vul één keer je authtoken in.
3. Klik op **Start** en open de link op je Quest. Maak er een bladwijzer van.

Om te testen kun je de map `voorbeeld` kiezen in de installatiemap.
